РАЗДЕЛ 1. ДЛЯ ПОЛЬЗОВАТЕЛЕЙ
================================================================

1.1 НАЧАЛО РАБОТЫ
-----------------
1. Найди бота в Telegram по username или перейди по ссылке.
2. Нажми кнопку "Запустить" или отправь команду /start.
3. Бот покажет приветственное сообщение с текущим балансом
   и главное меню с кнопками.

Реферальная ссылка: если ты перешёл по чужой ссылке вида
  t.me/ИМЯ_БОТА?start=ref_XXXXX
бонусные токены автоматически начислятся пригласившему.


1.2 ГЕНЕРАЦИЯ ИЗОБРАЖЕНИЙ
--------------------------
Нажми кнопку "🎨 Генерировать" в главном меню.
Шаги:

  Шаг 1 — Выбери нейросеть (Nano Banana / Seedream / Midjourney)

  Шаг 2 — Введи промт
    Опиши что хочешь увидеть на изображении.
    Пример: "красивый закат над горами, фотореализм, 8K"
    Промт можно писать на русском или английском языке.

  Шаг 3 — Преференс (необязательно)
    Дополнительные параметры стиля, которые влияют на результат.
    Пример: "cinematic lighting, dramatic, shallow depth of field"
    Можно пропустить — нажми "Пропустить".

  Шаг 4 — Качество
    • 2K — стандартное качество, дешевле
    • 4K — высокое качество, дороже

  Шаг 5 — Количество изображений
    Выбери от 1 до 4 штук.
    Стоимость умножается на количество.

  Шаг 6 — Подтверждение
    Бот покажет итоговую стоимость и все параметры.
    Нажми "✅ Подтвердить" для запуска или "◀️ Назад" для отмены.

После подтверждения бот ответит "⏳ Генерация запущена!" и
через 30–120 секунд пришлёт готовые изображения отдельным
сообщением. Не нужно ничего ждать — можно продолжать
пользоваться ботом.

Если что-то пошло не так — токены возвращаются автоматически.


1.3 МОДЕЛИ НЕЙРОСЕТЕЙ
----------------------
🍌 NANO BANANA
  Быстрая генерация на базе технологий Google.
  Лучше всего подходит для: общих сцен, пейзажей, абстракций.
  Скорость: ~15–30 секунд.

🌱 SEEDREAM
  Специализируется на фотореалистичных изображениях.
  Лучше всего подходит для: портретов, людей, предметной съёмки.
  Скорость: ~20–40 секунд.

🎨 MIDJOURNEY
  Художественный стиль с высокой детализацией.
  Лучше всего подходит для: арта, иллюстраций, фэнтези, концептов.
  Скорость: ~60–120 секунд.

Совет: для лучшего результата пиши промт на английском языке
и указывай стиль (photorealistic, oil painting, anime и т.д.)


1.4 ТОКЕНЫ
-----------
Токены — внутренняя валюта бота. Списываются при каждой
успешной генерации. При ошибке — возвращаются.

Стоимость (по умолчанию, может быть изменена администратором):
  • 2K качество — 10 токенов за 1 изображение
  • 4K качество — 20 токенов за 1 изображение

Примеры:
  • 2 изображения в 2K = 10 × 2 = 20 токенов
  • 4 изображения в 4K = 20 × 4 = 80 токенов

Текущий баланс всегда виден в главном меню и на экране
подтверждения генерации.

Как получить токены:
  - Купить пакет токенов (раздел "💰 Баланс")
  - Пригласить друга по реферальной ссылке (+50 токенов)
  - Получить подписку (включает стартовые токены)
  - Быть добавленным в список администраторов
    (генерация бесплатна для администраторов)


1.5 ПОПОЛНЕНИЕ БАЛАНСА
-----------------------
Нажми "💰 Баланс" в главном меню, затем "💳 Купить токены".

Доступные пакеты (цены могут быть изменены администратором):
  • 100 токенов  — 99 ₽
  • 300 токенов  — 249 ₽
  • 700 токенов  — 499 ₽
  • 1500 токенов — 999 ₽

Нажми на нужный пакет — токены зачислятся мгновенно.


1.6 ПОДПИСКА
------------
Нажми "💰 Баланс" → "👑 Купить подписку".

Доступные тарифы (цены могут быть изменены администратором):
  • 🥉 Базовый    — 299 ₽/мес
  • 🥈 Стандарт   — 599 ₽/мес
  • 🥇 Про        — 999 ₽/мес

Преимущества подписки:
  • Приоритет в очереди генерации
  • Бонусные токены каждый месяц
  • Скидка на пакеты токенов

Подписка действует 30 дней с момента активации.
При повторной покупке подписка обновляется (план и срок),
предыдущая автоматически заменяется.


1.7 РЕФЕРАЛЬНАЯ ПРОГРАММА
--------------------------
Нажми "🔗 Рефералы" в главном меню.

Как работает:
  1. Скопируй свою реферальную ссылку.
  2. Отправь её другу.
  3. Когда друг нажмёт /start по твоей ссылке —
     ты получишь 50 токенов автоматически.

Условия:
  • Бонус начисляется только за новых пользователей
    (тех, кто ещё не запускал бота).
  • Нельзя пригласить самого себя.
  • Количество рефералов и заработанные токены видны
    на странице "🔗 Рефералы".


================================================================
РАЗДЕЛ 2. ДЛЯ АДМИНИСТРАТОРОВ
================================================================

Администратор — пользователь, чей Telegram ID указан в
переменной ADMIN_IDS в файле .env.

Администраторы видят дополнительную кнопку "⚙️ Админ" в
главном меню. Генерация для них бесплатна.


2.1 ДОСТУП К ПАНЕЛИ
--------------------
Нажми "⚙️ Админ" в главном меню.
Разделы панели: Статистика, Пользователи, Рассылка, Тарифы.


2.2 СТАТИСТИКА
--------------
Раздел "📊 Статистика" показывает:
  • Общее число пользователей
  • Число заблокированных
  • Число активных подписок
  • Генерации по каждой модели (Nano Banana / Seedream / Midjourney)
  • Общий доход
  • Доход за последние 30 дней
  • Доход за последние 7 дней
  • Конверсия в платящих пользователей (%)


2.3 УПРАВЛЕНИЕ ПОЛЬЗОВАТЕЛЯМИ
------------------------------
Раздел "👥 Пользователи".

Поиск пользователя:
  • По Telegram ID — введи числовой ID
  • По username — введи @username или username без @

После поиска откроется карточка пользователя:
  - ID, имя, username, баланс токенов, число рефералов, статус блокировки

Доступные действия:
  • Заблокировать / Разблокировать
    Заблокированный пользователь не может использовать бота.
    Получает сообщение "⛔ Вы заблокированы".

  • Выдать подписку
    Выбери тариф (basic / standard / pro) и срок (7 / 30 / 90 дней).
    Подписка активируется мгновенно.


2.4 РАССЫЛКА
------------
Раздел "📢 Рассылка".

  1. Отправь сообщение для рассылки.
     Поддерживаются: текст, фото с подписью, видео с подписью.
  2. Бот покажет предпросмотр и количество получателей.
  3. Подтверди отправку кнопкой "✅ Отправить".

Рассылка отправляется всем незаблокированным пользователям.
Пауза между отправками — 0.05 сек (защита от флуда Telegram).
После завершения бот покажет количество успешных отправок
и ошибок.


2.5 УПРАВЛЕНИЕ ТАРИФАМИ
------------------------
Раздел "💰 Тарифы". Все цены сохраняются в Redis и применяются
мгновенно без перезапуска бота.

Стоимость генерации:
  Введи два числа через пробел: сначала цена 2K, потом 4K.
  Пример: 10 20

Пакеты токенов:
  Введи каждый пакет с новой строки в формате: токены цена
  Пример:
    100 99
    300 249
    700 499
    1500 999

Цены подписок:
  Введи каждый тариф с новой строки в формате: план цена
  Доступные планы: basic, standard, pro
  Пример:
    basic 299
    standard 599
    pro 999


================================================================
РАЗДЕЛ 3. ДЛЯ ВЛАДЕЛЬЦА
================================================================

Владелец — пользователь, чей Telegram ID указан в переменной
OWNER_ID в файле .env. Владелец также должен быть в ADMIN_IDS
чтобы видеть кнопку "⚙️ Админ".


3.1 РЕЖИМ ОБСЛУЖИВАНИЯ (/maintenance)
--------------------------------------
Скрытая команда, доступна только владельцу.
Отправь боту: /maintenance

Первый вызов — режим ВКЛЮЧАЕТСЯ:
  "🔴 Режим обслуживания включён"
  Все пользователи (кроме владельца) получают сообщение:
  "🔧 Бот временно недоступен. Ведутся технические работы."
  и не могут пользоваться ботом.

Повторный вызов — режим ВЫКЛЮЧАЕТСЯ:
  "✅ Режим обслуживания выключен — бот работает в штатном режиме."
  Все пользователи снова получают доступ.

Владелец продолжает работать в любом режиме.

РАЗДЕЛ 4. ДЛЯ РАЗРАБОТЧИКА / ДЕПЛОЙ
================================================================

4.1 ТРЕБОВАНИЯ
--------------
  • Docker и Docker Compose
  • Telegram Bot Token (от @BotFather)
  • API ключ WaveSpeed (для Nano Banana и Seedream)
  • API ключ midapi.ai (для Midjourney)


4.2 НАСТРОЙКА .env
-------------------
Скопируй .env.example в .env и заполни:

  cp .env.example .env

Обязательные поля:
  BOT_TOKEN          — токен бота от @BotFather
  BOT_USERNAME       — username бота без @
  OWNER_ID           — Telegram ID владельца (узнать у @userinfobot)
  ADMIN_IDS          — список ID администраторов, например [123456789]
  DB_NAME            — имя базы данных
  DB_USER            — пользователь PostgreSQL
  DB_PASSWORD        — пароль PostgreSQL

Необязательные (есть дефолты):
  WAVESPEED_API_KEY  — ключ для Nano Banana и Seedream
  MIDJOURNEY_API_KEY — ключ для Midjourney
  YUKASSA_SHOP_ID    — ID магазина ЮКасса (если нужна реальная оплата)
  YUKASSA_SECRET_KEY — секретный ключ ЮКасса
  TOKENS_2K          — стоимость 2K генерации (по умолчанию: 10)
  TOKENS_4K          — стоимость 4K генерации (по умолчанию: 20)
  REFERRAL_BONUS_TOKENS — бонус за реферала (по умолчанию: 50)


4.3 ЗАПУСК
----------
  # Первый запуск (включая миграции БД):
  docker-compose up -d

  # Просмотр логов:
  docker-compose logs -f bot
  docker-compose logs -f worker

  # Перезапуск после изменения кода:
  docker-compose restart bot worker

  # Полная пересборка (после изменения зависимостей):
  docker-compose up -d --build --force-recreate


4.4 МИГРАЦИИ БД
----------------
Миграции применяются автоматически при каждом запуске бота.

Применить вручную:
  docker-compose run --rm migrate alembic upgrade head

Создать новую миграцию после изменения моделей:
  Написать файл в migrations/versions/ вручную или через
  docker-compose run --rm migrate alembic revision --autogenerate -m "описание"

Проверить текущую версию БД:
  docker-compose exec db psql -U DB_USER DB_NAME -c "SELECT * FROM alembic_version;"

Цепочка миграций:
  76ba33c9f986 (initial) → 288f9f9cfa36 (empty) → a1b2c3d4e5f6 (текущая)


4.5 СТРУКТУРА ПРОЕКТА
----------------------
  chatbot_tg/
  ├── bot/
  │   ├── handlers/          — обработчики команд и кнопок
  │   │   ├── start.py       — /start, главное меню, помощь
  │   │   ├── generate.py    — флоу генерации изображений
  │   │   ├── balance.py     — баланс, покупка токенов и подписок
  │   │   ├── referral.py    — реферальная программа
  │   │   └── admin.py       — админ-панель, /maintenance
  │   ├── keyboards/         — клавиатуры (кнопки)
  │   └── middlewares/
  │       ├── auth.py        — проверка пользователя, режим обслуживания
  │       └── throttling.py  — защита от спама
  ├── core/
  │   └── config.py          — настройки из .env
  ├── db/
  │   ├── models/            — модели SQLAlchemy (таблицы БД)
  │   └── repositories/      — слой работы с БД
  ├── migrations/            — миграции Alembic
  ├── services/
  │   ├── ai/
  │   │   ├── nano_banana.py — генерация через WaveSpeed API
  │   │   ├── seedream.py    — генерация через WaveSpeed API
  │   │   └── midjourney.py  — генерация через midapi.ai
  │   └── settings_service.py — хранение настроек в Redis
  ├── webhook/
  │   └── app.py             — вебхук для ЮКасса (порт 8080)
  ├── workers/
  │   ├── celery_app.py      — настройка Celery
  │   └── tasks.py           — фоновые задачи (генерация, уведомления)
  ├── tests/                 — автотесты (pytest)
  ├── docker-compose.yml     — конфигурация сервисов
  ├── Dockerfile
  ├── .env.example           — шаблон переменных окружения
  └── requirements.txt


СЕРВИСЫ В DOCKER COMPOSE
  bot      — основной процесс Telegram бота (polling)
  worker   — Celery воркер (фоновая генерация изображений)
  beat     — Celery beat (периодические задачи: уведомления о балансе)
  webhook  — FastAPI сервер для приёма платежей ЮКасса (порт 8080)
  db       — PostgreSQL 15
  redis    — Redis 7 (брокер Celery + хранение настроек)
  migrate  — одноразовый контейнер для применения миграций
